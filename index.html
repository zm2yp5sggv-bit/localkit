Frequently asked questions

Are my files really never uploaded?

Correct. Each tool on LocalKit is a small program that runs inside your browser tab. When you pick a file, the browser reads it from your disk and processes it in local memory. There is no upload step at all — you can even disconnect from the internet and keep using most tools.

Is it really free?

Yes. LocalKit is supported by unobtrusive ads, so all tools stay free and unlimited for everyone.

Which browsers are supported?

Any modern browser: Chrome, Edge, Firefox, Safari and Opera, on desktop and mobile. For the image tools we recommend a recent browser version for the best compression formats.

Can I use the tools on my phone?

Yes — the site is fully responsive and all tools work on Android and iOS browsers.
